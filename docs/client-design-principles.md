# 工作持续，客户端从容应对连接变化

Alu Dock 是部署在用户自有主机上的单用户、多主机 Agent 工作平台。Host 与 Worker 托管工作的持续运行，客户端提供观察、输入和控制入口。同一份工作不依赖某个界面持续在线，也不因更换入口而分叉。

桌面端与移动端应按各自的实际使用场景设计。尤其在移动端，弱网、断连、切网和前后台切换是正常使用条件，而不是需要重置整个界面的异常。连接变化不应清空已有内容、打断本地编辑，或迫使用户反复刷新、重连和重新输入。

客户端可以暂时尚未取得远端最新状态，但必须如实区分已确认、等待和结果未明。本地交互应及时响应，远端操作应及时反馈；恢复连接后按真实工作状态补齐信息，不冒充成功，不擅自重复执行结果不明的操作。
