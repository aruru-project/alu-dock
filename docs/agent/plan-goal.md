# 规划与自动推进

Pi Worker 自动加载这项能力，沿用现有客户端的命令、对话框和状态栏。

## 先规划

输入 `/plan 需求`，Agent 会先用只读工具调查，必要时问你影响方向的问题。准备好后展示完整计划，让你选择：

- **按此执行**：执行这份计划一次
- **执行并自动推进到完成**：执行计划，并用默认 10 轮继续推进
- **我来改**：编辑后回到选择框
- **继续讨论**：留在规划中，等你补充

单独输入 `/plan` 可以进入或退出规划。补充一句话不会让未变化的计划重新审批；计划正文改变才需要重新选择。长计划会先打开完整编辑器。

规划时只提供只读工具和规划工具，调用时仍检查嵌套工具。自定义工具的 `readOnlyHint: true` 声明需要可信；这不是操作系统沙箱，已安装扩展自己的代码仍有普通 Worker 权限。

## 直接推进目标

输入 `/goal 修到这组测试通过，不提交、不部署`，默认推进 10 轮。无需先写计划；也可用 `/goal --rounds 5 目标` 指定轮数。已有目标时，新内容会替换它。

单独输入 `/goal`，按当前状态选择 **继续、暂停、结束、再给 10 轮**。追加预算沿用原目标和已做进展，不用重新开始。

- 正在回复时开始或继续目标，当前回复照常结束，再接上目标
- 第一轮和自动续轮计入预算；同轮工具往返、重试、压缩和你的补充不另计
- 按 Esc 或“中止当前回复”，目标一起暂停；普通聊天不会把它重新打开
- 轮数用完会停下，模型不能自行加预算。只有轮数限制，没有计时中止
- 完成时给出结果与依据，结束后清空目标状态和面板；暂停、受阻、预算用尽只保留一行继续提示

Goal 沿用你原来的授权，不代表允许额外付款、提交或部署。完成依据是模型报告，不能把未运行的检查当成通过。

## 回来继续

计划和目标只保存在 Pi 当前会话分支。客户端断开不影响已开始的工作；重启、reload、fork 或切换分支后，保留内容和已用轮数，但等你用 `/goal` 选择继续。旧版本记录可以读取，旧时间期限不再生效。

全新空会话在首条对话出现前仍遵循 Pi 原生保存规则。规划工具只在规划时提供，目标进展工具只在自动推进时提供；普通聊天不会反复附加旧目标或整份计划。
