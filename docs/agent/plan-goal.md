# 规划与自动推进

## 先规划，再执行

输入 `/dock-plan 需求`。Agent 先调查项目、需要时问你取舍，这期间它不能修改文件。准备好后，完整计划会在编辑器里打开，你可以直接改；保存后选择：

- **按此执行**：按这份计划做一次
- **执行并自动推进到完成**：按计划做，并自动推进最多 10 轮
- **继续讨论**：留在规划中，等你补充

保存编辑器不等于同意执行，只有选了执行才会开始。确认前补充一句话，不会让这次确认作废。按 Esc 会关闭计划并停在规划中。单独输入 `/dock-plan` 可以进入或退出规划。

规划期间会临时打开 read、grep、find、ls 等读取工具，结束规划时收回。规划期间你在工具设置里改过工具，结束时就保留你改完的样子，不再收回。

## 直接设一个目标

输入 `/dock-goal 修到这组测试通过，不提交、不部署`，Agent 会自动一轮接一轮地做，默认最多 10 轮。也可以写 `/dock-goal --rounds 5 目标` 指定轮数。新目标会替换旧目标。

单独输入 `/dock-goal`，按当前状态选择 **继续、暂停、结束** 或 **再给 10 轮**。

- 正在回复时设目标或选继续，当前回复会照常说完，然后接着推进
- 只有自动推进的那一轮算轮数；你中途补充的话、工具调用、重试都不算
- 按 Esc 会同时暂停目标；之后普通聊天不会让它自己恢复
- 轮数用完就停下，选"再给 10 轮"会沿用原目标和已有进展
- 完成时会留下结果和依据，然后状态栏清空

目标不会扩大你原来给的授权，也不代表允许付款、提交或部署。完成依据是 Agent 的报告，需要你自己判断是否可信。

## 回来继续

重启、重新加载或在历史里切换位置后，计划和已用轮数都还在，但目标不会自己开始，要你用 `/dock-goal` 选择继续。
