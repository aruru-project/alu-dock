# AluDock UI assets

- `console_icon_small.png` and `new_logo_small.png` are the exact assets used by Rails Alu WebConsole.
- `aludock-icon.png` is copied from the approved Dock application icon at `alu_dock/assets/icon.png` and is used for native-client branding and the favicon.

The WebConsole baseline intentionally does not substitute generated art or alternate character crops.
