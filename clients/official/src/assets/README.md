# AluDock UI assets

- `console_icon_small.png` and `new_logo_small.png` are the exact assets used by Rails Alu WebConsole.
- Dock branding and the favicon import the canonical root `assets/icon.svg` directly; do not add an independently editable copy here.

The WebConsole baseline intentionally does not substitute generated art or alternate character crops. Agent conversation avatars continue to use `console_icon_small.png`.
