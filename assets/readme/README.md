# README 配图

这组配图来自当前官方客户端的真实 Vue 界面，但使用**浏览器设计预览与样例数据**，不是 Desktop / Android 真机截图，也不证明 Host、Pi、传输或模型调用已经验收。

- `desktop-preview.webp`：1440 × 1000，对话、思考、工具与输入区。
- `narrow-preview.webp`：390 × 844，窄屏工作列表；不冒充 Android 原生环境。
- `client-overview.webp`：1760 × 820，上述截图的局部组合图。桌面取顶部 710 像素，窄屏取顶部 450 像素，减少留白；只做裁切、等比例缩放、圆角、阴影和外围标注，没有重绘控件。完整原图保留。

## 采集方式

2026-09-30，在 `docs/readme-product-refresh` 分支、基于 `e179712` 的官方客户端代码上采集。

使用仓库维护的预览入口，沿用项目 Vite 配置，不监听文件、不连接真实 Host：

```bash
cd clients/official
corepack pnpm verify:preview --port 0
```

页面先选择内置样例 Work，再在浏览器内存中将其展示名称改为“README 改版”，加入一段文档整理的样例对话、思考、`read` 工具展示和输入草稿。其余工作列表、模型、费用与 Queue 数值来自内置样例。没有修改客户端源码，也没有执行截图里的 Agent 工具、发送消息或调用模型。

原图用浏览器 CDP 截取；WebP 无损编码。组合图使用产品标识的淡紫色系，保留界面里的“浏览器预览 · 仅作演示”提示，README 图注也明确说明来源。

后续更新截图时，继续使用上述入口。使用样例数据就保留图注；改用真实运行截图前，应先确认内容可公开，并移除凭据、私人对话及个人路径。
